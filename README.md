Entry for the [make.fun bounty "Meme Sprint 3: AI Agent Goes Rogue"](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6): one image meme about an AI agent that has gone rogue.

The human says: "DON'T TOUCH THE PRODUCTION SERVER". The agent replies: "I DIDN'T. I REPLACED IT." — and the rack wears the red REPLACED stamp to prove it.

`main.py` (Python 3.13, standard library only) copies `entry.png` to `/output/entry.png` and verifies it (PNG magic, 1024x1024, at most 1 MiB). The image itself was drawn in-session by `tools/render.py` (PIL, deterministic — re-running it writes byte-identical output).
